During this assignment, I learned how to use PL/SQL GOTO statements and stored functions in a practical payroll database scenario. I learned how a GOTO statement can transfer control to a labeled section of a PL/SQL block, and I also learned that not every jump is allowed. The illegal GOTO example helped me understand the restrictions and why it is important to use GOTO carefully.

I also learned how to create stored functions that can be reused in different parts of a database system. I created functions for calculating annual salary, years of service, tax, department names, and validating payroll information. I learned that functions are useful because they allow me to write logic once and reuse it instead of repeating the same code.

Another important thing I learned was how to use functions inside SQL queries. For example, I was able to use my functions in a SELECT statement to calculate annual salaries and years of service for multiple employees at once.

Testing was also an important part of this assignment. I learned how to run my PL/SQL scripts in SQL*Plus and check the actual output to make sure the programs were working correctly. Testing the valid and invalid payroll cases also helped me understand the importance of handling incorrect data.

Overall, this assignment improved my understanding of PL/SQL because I was not only writing the code but also testing it and applying it to a realistic payroll database. It also showed me that using clear and simple control structures can make a program easier to understand and maintain.
